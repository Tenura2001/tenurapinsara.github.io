Connect to your repo

Create one at github.com/settings/tokens → "Generate new token (classic)" → tick the repo scope (or, for a fine-grained token, give it Contents read/write on this repo). The token is saved only in this browser's local storage — it is never uploaded anywhere except directly to GitHub's API, and never gets committed to your site.
